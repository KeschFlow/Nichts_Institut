# VEB Kombinat der LPG des Nichts

**Wir machen nichts. Aber richtig.**

**Erster Vorsitzender:** Genosse ERICH

Ein Satireprojekt von **Kesch**. Für alle, die schon genug zu tun haben – und endlich eine Stelle brauchen, die ihre Untätigkeit ordnungsgemäß nicht bearbeitet.

> Kein echtes Amt. Kein Staatsbetrieb. Keine Behörde. Nur sehr gewissenhaftes Nichtstun.

## Was das Institut macht

- **Nichtstun beantragen:** Ein Vorhaben eintragen oder eine Vorlage auswählen.
- **Bescheid erhalten:** Die Verwaltung erstellt einen absurden, nicht amtlichen Bescheid.
- **Bescheid teilen:** Als Bild herunterladen oder freiwillig an andere weitergeben.
- **Nichtstun unterstützen:** Wer den Witz mag, kann einen frei gewählten Betrag über Stripe geben.

Die Nutzung des Bescheids ist kostenlos und unabhängig von einer Zahlung. Eine Unterstützung ist **einmalig und freiwillig** – kein Abo, keine Beteiligung, keine Rendite und keine steuerlich absetzbare Spende.
